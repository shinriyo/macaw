# Changelog

All notable changes to Macaw are listed here.

## 0.0.6

- Adds a GUI save target selector for User or Workspace settings.
- User settings can store Macaw rules without creating or modifying a repository `.vscode/settings.json`.

## 0.0.5

- Adds this changelog so users can review all release history from the Marketplace and repository.

## 0.0.4

- Updates path rule color chips immediately while editing colors.
- Keeps copied color values in sync with the latest selected color.

## 0.0.3

- Fixes the README logo URL for the Visual Studio Marketplace page.
- Uses a GitHub raw image URL so the logo renders outside the repository.

## 0.0.2

- Removes the standalone `Macaw: Apply` command from the Command Palette.
- Keeps `Apply`, `Clear`, and rule management inside the GUI rules editor.

## 0.0.1

- Initial public release.
- Adds path-based workspace color and title rules.
- Adds language-based workspace colors.
- Adds automatic title updates.
- Adds the `Macaw: Open Rules` GUI editor.
- Adds multilingual README content and release packaging.
